## Security-first product thinking

I focus on building software that is not only useful, but also dependable, understandable, and safe to operate.

- Start with the real problem
- Ship practical product iterations
- Keep systems secure by default
- Keep human decision-making explicit
- Improve from evidence, not assumptions
