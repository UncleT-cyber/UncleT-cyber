## Security principles

| Principle | How I approach it |
| --- | --- |
| **Authorization first** | Test and investigate only systems and data within explicit permission and scope. |
| **Evidence over assumption** | Keep observations, tool outputs, and hypotheses distinct and traceable. |
| **Human oversight** | Use automation to support analysts—not replace their judgment or authorization. |
| **Least privilege** | Limit capabilities and access to what a task actually requires. |
| **Accountability** | Prefer auditable workflows and explainable outcomes. |
